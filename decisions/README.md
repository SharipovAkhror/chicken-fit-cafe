# Архитектурные решения

Здесь хранятся ADR — короткие записи о значимых и труднообратимых решениях.

## Правила

1. Номер выдаётся последовательно: `ADR-001`, `ADR-002`.
2. Статусы: `proposed`, `accepted`, `superseded`, `rejected`.
3. Принятое решение не переписывается задним числом; изменение оформляется новым ADR.
4. Каждый ADR ссылается на связанные claims и issue.
5. Шаблон: [`../templates/adr.md`](../templates/adr.md).
