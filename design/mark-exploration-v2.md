# Mark exploration v2

Три полоски и CF-монограмма из design pack v1 **сняты** с роли primary mark.
Ниже — четыре направления **иконки** (app / favicon / sticker / stamp).
Wordmark `ChickenFit` и шрифт — отдельный следующий шаг после выбора mark.

## Бриф знака

| | |
| --- | --- |
| Должен сказать | Сытный куриный обед; слоёная/сэндвич-форма; современный Самарканд без фольклора |
| Не должен | Диета, «fit-зал», AI-декор, орнамент, три параллельные линии как лого |
| Техника | 1 цвет, 2 цвета max; круг или скруглённый квадрат 1:1; 16–512 px |
| Референс-мышление | Простые food marks: один жест, сильный силуэт, ноль украшений |

## Направление M1 — «Разрез» (product cross-section)

**Идея:** один компактный силуэт разреза бургер-самсы: корочка → слои →
начинка. Не «три полоски», а **единая форма** с внутренним негативом.

- Плюс: прямо про продукт-герой (C-003).
- Риск: на 16 px слои слипнутся — нужна упрощённая 1-цветная версия.
- Файл: `assets/marks-v2/m1-bite.svg`

## Направление M2 — «Миска обеда» (bowl)

**Идея:** круглая миска + намёк на продукт сверху (полоска курицы / пар).
Гостеприимство, обед, «сытно и по-человечески».

- Плюс: отлично для social avatar и вывески-кнопки.
- Риск: может уйти в generic healthy-bowl — держать терракоту и графит, без зелени-клише.
- Файл: `assets/marks-v2/m2-bowl.svg`

## Направление M3 — «Стрипс» (strip)

**Идея:** одна изогнутая полоска курицы (fillet/strip) в круге — еда, хруст,
движение. Не три линии бренда, а **форма продукта**.

- Плюс: очень просто, штампуется, масштабируется.
- Риск: абстрактно; без wordmark может быть непонятно «что за бренд».
- Файл: `assets/marks-v2/m3-strip.svg`

## Направление M4 — «Гребешок» (crest bird)

**Идея:** крайне упрощённый профиль птицы / гребешок — 3–4 кривые, без глаза и
клюва-карикатуры. Характер «курица» без клише.

- Плюс: самый «логотипный» характер; хорошо живёт отдельно от названия.
- Риск: легко скатиться в cartoon — только строгая геометрия.
- Файл: `assets/marks-v2/m4-crest.svg`

## Как выбирать (для владельца)

Отметь **одно** primary + опционально secondary:

1. Узнаёшь ли без текста через 1 секунду?
2. Хочется ли наклейку на крафт-короб?
3. Не стыдно на фасаде 1×1 м?
4. Не похоже на Canva-шаблон / Midjourney icon pack?

## Следующий шаг после выбора

1. Довести выбранный mark: оптика, 1-color / 2-color / reverse.
2. Wordmark: тест 2–3 гротесков (не только Unbounded) + кириллица/латиница UZ.
3. Lockup: mark + ChickenFit, clear space, min size.
4. Только потом — stamp на белые бланки упаковки.
