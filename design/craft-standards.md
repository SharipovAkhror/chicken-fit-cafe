# Стандарты craft-дизайна

> Роль: только **visual-designer**. Мышление — практикующий бренд-дизайнер
> (Pentagram / Collins / local craft), не генератор картинок.

## 1. Что отвергнуто (anti-slop)

Владелец (2026-07-25) зафиксировал:

| Что | Вердикт | Почему |
| --- | --- | --- |
| Social avatar / mark с тремя полосками | **reject** | Нет характера, «декор вместо знака» |
| Три линии как фирменный модуль-иконка | **reject as primary mark** | Не читается как продукт, выглядит шаблонно |
| AI packaging/storefront boards | **не финал** | Видно генерацию; слишком «лофт-рендер», не производство |
| Сложная «дизайнерская» упаковка из воздуха | **reject** | Нужны простые картонные бланки, доступные в Узбекистане |

Цвета (терракота / pastry / графит / олива) и тёплый «жёлтый» свет интерьера —
**пока держим**. Это настроение, не финальная фотосистема.

## 2. Mindset настоящего дизайнера

1. **Сначала функция, потом красота.** Знак должен работать 16×16 px, на
   крафт-штампе и на вывеске. Если не работает в одном цвете — это не знак.
2. **Один смысловой жест.** Курица *или* слоёный разрез *или* миска — не всё
   сразу. Зритель считывает за 0.3 сек.
3. **Ручная геометрия.** Кривые, толщины, оптические выравнивания правятся
   человеком. Никаких «трёх полосок и Unbounded на всё».
4. **Материал мира.** Крафт, жир, крошка, рука — правда fast-casual. Не
   глянцевый CGI-лофт как единственный язык.
5. **Производимость.** Упаковка = то, что реально купить у OSQ / top-box.uz /
   местной типографии, потом штамп 1–2 цвета.
6. **Do / Don’t.** Каждый носитель в брендбуке — с запретами.
7. **Нет AI-slop в финале.** Генерация допустима только как черновой mood;
   финал — вектор, сетка, макет, фото/мок на реальном бланке.

## 3. Порядок работ (как в студии)

```
Mark (иконка) → Wordmark (шрифт) → Lockup
     → Color lock → Type lock
     → Packaging blanks (белые) → brand stamp
     → Stickers / posters / banners
     → Brandbook PDF + Canva Brand Kit
```

**Стоп-правило:** пока нет утверждённого mark + wordmark — не брендируем
упаковку и не печатаем тираж. Бланки собираем и утверждаем **пустыми**.

## 4. Критерии «не slop»

- [ ] Знак узнаётся в силуэте (заливка одним цветом).
- [ ] Нет лишних градиентов, теней, «AI glow», псевдо-3D.
- [ ] Нет клише: купол, самолёт, мультяшная курица с глазами, поварской колпак.
- [ ] На крафте 1+0 (терракота) выглядит уверенно.
- [ ] Социальный аватар = mark, не коллаж.
- [ ] Макет брендбука сам выглядит как бренд (не дефолтный Notion).
