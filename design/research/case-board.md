# Доска кейсов (value extraction, не копирование)

Каждый кейс: **что работает** → **что переносим в ChickenFit** → **что отвергаем**.

## 1. KOISI Tokyo packaging (Tubik) — JP restraint

| | |
| --- | --- |
| Контекст | Японский ресторанный packaging system |
| Работает | 4 цвета; shape/space/texture; no gradient/foil; знак как язык, не декор |
| Переносим | Лимит палитры; штамп на бумаге; «presence not decoration» |
| Не берём | Лисы/журавли/кои как мотив — наш продукт другой |

## 2. Yoshinoya lettermark (Chermayeff & Geismar & Haviv)

| | |
| --- | --- |
| Контекст | Глобальная сеть, кросс-культурная читаемость |
| Работает | Сила **буквы**, не иллюстрации миски; характер в lettering |
| Переносим | Wordmark-led вариант (семья D): ChickenFit может жить без «курицы-картинки» |
| Не берём | Красный fast-food шаблон сетей |

## 3. Koboru / minimal sushi branding

| | |
| --- | --- |
| Контекст | Minimal food branding |
| Работает | Тишина, крупный продукт или пустота, мало элементов |
| Переносим | Воздух в lockup; один hero product shot позже |
| Не берём | Sushi visual language |

## 4. JP convenience / gyudon packaging culture (общие паттерны)

| | |
| --- | --- |
| Контекст | Уличный и network F&B Японии |
| Работает | Функция: держит, греет, читается за 1 сек; честный материал |
| Переносим | Крафт + 1–2 краски; иконка-штамп; короткие слова |
| Не берём | Перегруженный «премиум-бокс» |

## 5. Western craft chicken (анти-паттерн + редкие хорошие)

| | |
| --- | --- |
| Контекст | Массовый chicken QSR |
| Плохо | Cartoon rooster, flame, badge «EST. 20XX», 3D oil chicken |
| Хорошо (редко) | Геометрический crest; wordmark; monochrome stamp |
| Переносим | Отказ от cartoon; crest только если строго (семья C) |

## 6. Central Asian / Samarkand hospitality (принцип, не орнамент)

| | |
| --- | --- |
| Контекст | C-016 локальность = гордость + сервис |
| Работает | Тёплый свет, щедрость порции, уважение |
| Переносим | Тон сервиса; pastry/terracotta как «печь/тесто» |
| Не берём | Купола, орнамент, «этнический паттерн» на всё |

## 7. Specialty coffee craft (метод, не кофе)

| | |
| --- | --- |
| Контекст | Лучшие specialty-айдентики 2018–2025 |
| Работает | Странный mark ok, если система жёсткая; крафт; type-led |
| Переносим | Право на «нестандартный» знак (enso, seal, fold) |
| Не берём | Кофейное зерно / чашка как клише |
