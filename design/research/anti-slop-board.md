# Anti-slop board

Если элемент попадает сюда — **не улучшаем, удаляем** из shortlist.

## Визуальный slop (food)

| # | Паттерн | Почему slop |
| --- | --- | --- |
| S1 | Мультяшная курица с глазом | Детский QSR, нет доверия «сытный обед» |
| S2 | Огонь / chili / «CRISPY» badge | Шум, глобальный фастфуд-клише |
| S3 | 3D glossy burger floating | AI/stock look |
| S4 | Фиолетовый/неон градиент | Не наш мир (C-020) |
| S5 | Купол / самолёт / орнамент | C-008 / anti-folklore |
| S6 | Три полоски как «лого» | Уже reject владельцем |
| S7 | CF в скруглённом квадрате «как app 2016» | Без характера |
| S8 | Japandi stock interior only | Интерьер ≠ бренд |
| S9 | Сакура / волна / тории | Китч «японский» |
| S10 | Слишком много оливкового «eco» | Fit ≠ diet (C-022) |

## Процессный slop

| # | Поведение | Замена |
| --- | --- | --- |
| P1 | Сразу 1 «финальный» лого | 20+ micro → cull → refine |
| P2 | Красивая картинка без 1-color test | Все mark → mono check |
| P3 | Шрифт «потому что модный» | Кириллица + UZ latin + вывеска |
| P4 | Canva template as identity | Template только для носителя после ядра |

## Критерий «оставить micro»

1. Узнаётся в 24×24  
2. Работает в одном цвете  
3. Не объясняется словами «это курица…» если не нужно  
4. Хочется штамп на крафт  
5. Не стыдно рядом с JP craft reference  

## Cull protocol (для владельца)

В галерее `design/assets/micro/gallery.html`:

- **♥ keep** — в shortlist  
- **~ maybe** — доработать  
- **× kill** — в anti-list  

Не спорим о ×. Улучшаем только ♥ и ~.
