# Color study

Владелец: терракота / тёплый свет / pastry **примерно ok**.  
Не ломаем мир C-020; **уточняем** оттенки и роли.

## Core (working)

| Token | HEX | Роль | 60/25/10/5 |
| --- | --- | --- | --- |
| pastry | `#F3E7D3` | бумага, фон | 60 |
| graphite | `#28211D` | текст, mono | 25 |
| terracotta | `#B94D2F` | бренд, CTA | 10 |
| olive | `#667447` | свежесть, редкий акцент | 5 |

## Micro-variations (тесты, не replace)

| ID | Change | Зачем |
| --- | --- | --- |
| V1 | terracotta → `#C45A38` (светлее) | мягче на крафте |
| V2 | terracotta → `#A33F26` (глубже) | ближе JP seal red-brown |
| V3 | pastry → `#EFE2CC` | чуть «тестовее» |
| V4 | graphite → `#1F1A17` | жёстче контраст |
| V5 | drop olive | 3-color system как KOISI spirit |
| V6 | olive → `#5C6B3A` | менее «диета» |

## На крафте (мысленный тест)

- Терракота 1+0 на kraft — must work  
- Графит 1+0 — must work  
- Pastry на kraft почти сливается → pastry = digital/print white-ish, не краска на крафте  

## Контраст (notes)

- graphite on pastry: pass body  
- pastry on terracotta: CTA ≥ 16px bold  
- olive on pastry: labels only  

См. живые swatches в gallery.
