# Сетка, lockup, clever detail

## 1. Feedback владельца (R1 → R2)

| Решение | Действие |
| --- | --- |
| Letter + seal marks | **kill** (D/E families) — слабые или слабая реализация |
| Type | **keep T2 Syne+Manrope, T4 Bricolage+Manrope, T7 Onest** |
| Color core | **оставить** terracotta / graphite / olive |
| Pastry | **чуть светлее** |
| Marks | пересобрать; меньше «радуги»; max 1–2 краски на знак |
| Новое | смотреть **icon+wordmark**; clever detail как Amazon/FedEx (не обязательно стрелка) |
| Темп | study first, не финал |

## 2. Золотой стандарт сетки (наш unit)

Canvas mark: **128×128**.  
Базовый unit **u = 8 px** (16×16 сетка).

| Правило | Значение |
| --- | --- |
| Stroke / gap | 1u или 2u (8 / 16) |
| Corner radius card | 3.5u (28) |
| Safe inset mark | ≥ 2u (16) от края |
| Optical center | чуть выше геометрического центра |
| Mono test | обязателен до shortlist |

Пропорции lockup (горизонт):

```
[ mark 5u high ] — 1u gap — [ wordmark x-height ≈ 3–3.5u relative ]
clear space around lockup ≥ height of "C"
```

Не golden spiral ради спирали. **Квадратная модульная сетка** + простые 1:2 / 1:3.

## 3. Архитектуры логотипа (что ещё смотреть)

Не только «иконка в квадрате».

| Архитектура | Пример мышления | Для ChickenFit |
| --- | --- | --- |
| **L1 Symbol + word** | icon слева, ChickenFit справа | классика app/фасад |
| **L2 Word only** | только ChickenFit, характер в буквах | wayfinding, чек |
| **L3 Word + clever detail** | Amazon smile, FedEx arrow | скрытый смысл в letterforms / underline |
| **L4 Stacked** | mark над словом | пакет, соц. |
| **L5 Monogram** | CF — только если сильный *после* word system | avatar secondary |

R1 почти только mark. **R2 = L1 + L3** в приоритете.

## 4. «Как Amazon / FedEx» — правильное понимание

Не «нарисуем стрелку».  
**Negative space / letter relationship** несёт смысл бренда.

| Бренд | Приём | Смысл |
| --- | --- | --- |
| FedEx | стрелка между E и x | скорость, A→B |
| Amazon | дуга a→z + smile | всё от A до Z + сервис |

Для ChickenFit кандидаты **смыслов** (не формы):

| Код | Скрытый смысл | Возможная форма |
| --- | --- | --- |
| H1 | **Слой** | негатив/вырез в «F» или между n/F как сдвиг слоёв |
| H2 | **Гостеприимство / fit** | мягкая дуга под Fit (не smile-клише Amazon) — «подходит» |
| H3 | **Разрез продукта** | горизонтальный gap в wordmark = тесто |
| H4 | **CF ligature** | C и F сцеплены как слои |
| H5 | **Круг/печать только внутри буквы** | не отдельный seal-mark |

Правило: clever detail **не кричит**; заметен со второго взгляда.

## 5. Минимализм цвета в лого

| Можно в одном lockup | Нельзя |
| --- | --- |
| graphite only (mono) | terra + olive + graph + pastry «радуга» |
| graphite + terracotta | 3+ brand colors в знаке |
| reverse: pastry on graphite | разные fill на каждой «полоске» ради красоты |

Olive — **не в лого**, только UI tags / food freshness later.
