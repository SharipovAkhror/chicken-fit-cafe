# Роль Canva и как делать красиво без него

## 1. Зачем упоминали Canva

Не потому что бренд «живёт в Canva».

Суть запроса владельца:

- не дизайнер по профессии;
- хочется передовые сетки, вкус, меньше slop;
- подписка Canva есть — вдруг там полезные инструменты.

Это **цель качества**. Canva — один из возможных **инструментов цеха**, не обязательный фундамент. Решение «подключать / нет» **не блокирует** проект.

## 2. Чем Canva помогает (узко)

| Помогает | Не помогает |
| --- | --- |
| Собрать постер / stories / меню **после** лого | Придумать уникальный характер |
| Brand Kit: хранить цвета и файлы | Заменить исследование и вкус |
| Mockup крафт-коробки из шаблона | Сделать «не как вся еда» |
| Быстрый PDF для команды | Заменить брендбук-мышление |

**Итог:** Canva = склад + быстрый выпуск носителей. Не = студия стратегии и знака.

## 3. Можем ли без Canva?

**Да. Полностью.**

| Задача | Без Canva |
| --- | --- |
| Правила, handoff | Git + Markdown |
| Цвета, токены | `design/tokens.css`, contrast check |
| Модульная типографика | typescale.com, modularscale.com |
| Макет брендбука | HTML/CSS → PDF (`tools/brandbook-pdf/`) |
| Вектор лого | SVG, ручная геометрия |
| Референсы | Behance, case studies, JP packaging |
| Anti-slop | Ограничения, do/don't, медленный craft |

Canva — **после** утверждённых ассетов, если захочется быстрее клепать посты.

## 4. Порядок (не генерировать сразу)

```
ИЗУЧЕНИЕ (сейчас)
  → референсы (JP craft F&B + anti-slop food)
  → принципы «берём / не берём»
  → 2–3 направления характера (слова + mood, без лого)
ВЫБОР ВЛАДЕЛЬЦА
РАЗРАБОТКА mark / type / color
БРЕНДБУК
КРАФТ-НОСИТЕЛИ
(опц.) Canva Brand Kit
```

**Сейчас не делаем:** новые иконки, PDF-брендбук «на глаз», Canva API.

## 5. Anti-slop

Slop = вкус вынесен из процесса.

Избегаем: stock-бургер 3D, неон-фуд, generic monogram, AI-лофт как единственный язык, «japanese = сакура + волна».

Хотим: один жест знака, воздух и сетка, материал (крафт, 1–2 краски), 4 цвета / 2 шрифта, do/don't.

## 6. Брендбук сейчас или лого сначала?

Брендбук **описывает** утверждённое ядро. Без mark / type / color — пустые страницы или slop.

1. Изучение + направления характера  
2. Выбор владельца  
3. Лого + шрифт + цвета  
4. Брендбук  
5. Крафт  
6. Canva по желанию  

## 7. Canva — статус решения

**Не принимаем. Отложено.** Проект идёт без Canva, пока ядро не готово.
