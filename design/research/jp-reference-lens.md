# JP-линза (исследование, не бренд-решение)

Документ для **учёбы**. Ничего не утверждает как финальный визуал.
Копировать чужой лого / сеть — запрещено. Брать **метод**, не картинку.

## Зачем

Нужен не «японский кафе в Самарканде».
Нужна необычность относительно массового фуд-брендинга — через
дисциплину: restraint, функция, материал, один жест.

## Что берём / не берём

| Берём | Не берём |
| --- | --- |
| Сдержанность, пустота, иерархия | Сакура, тории, maneki-neko |
| Функция упаковки > украшение | Gold foil + faux wabi-sabi |
| 1–2 акцента, много бумаги | Радуга «аппетитных» клише |
| Знак как система | Мультяшная еда |
| Честность крафта / штампа | Сток-идеальная еда |

Кейс-мышление (не клон): packaging вроде KOISI Tokyo — shape, space,
texture, 4 colors, no gradients.

Для ChickenFit: самаркандский обед + курица + слои × JP-дисциплина формы.

## Гипотезы характера (слова, не лого)

| Код | Характер |
| --- | --- |
| J1 | Тихий уверенный — воздух, графит+терракота |
| J2 | Ремесло обеда — крафт, штамп |
| J3 | Скорость + порядок — жёсткая сетка, product hero |
| J4 | Hybrid Samarkand×JP — продукт локальный, space японский; без фольклора |
