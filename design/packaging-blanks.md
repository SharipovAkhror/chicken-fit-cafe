# Упаковка: белые бланки

**Правило:** сейчас только **пустые / крафт / белые** конструкции.
Логотип и принт — после утверждения mark + wordmark.  
AI-борды удалены из repo; спецификация — только серийные бланки ниже.

## Принцип

1. Берём серийный бланк, который уже производят и возят в UZ/СНГ.
2. Утверждаешь SKU (размеры, крафт/белый).
3. Печать: 1+0 или 2+0 (терракота ± графит) — штамп / флексо, без
   полноцветного «дизайнерского» ламината на старте.
4. Функция: крошки слоёного теста, есть одной рукой, навынос + доставка.

## Рекомендуемый стартовый набор (к утверждению)

| # | Тип | Зачем | Цвет бланка | Ориентир поставщика |
| --- | --- | --- | --- | --- |
| P1 | **Коробка бургер M / L** (clamshell) | Флагман бургер-самса | Крафт или белый | OSQ BURGER M/L; top-box.uz «бургер коробки» |
| P2 | **Обертка / wrap** жиростойкая бумага | Дешевле коробки, для пика | Белая / крафт | top-box вощёная бумага; типографии Ташкента |
| P3 | **Fry / snack box S–M** | Гарнир, стрипсы, крылья | Крафт | OSQ FRY M/L; FAST FOOD BOX S/L |
| P4 | **Крафт-пакет с ручками** | Навынос, доставка 2–3 позиции | Крафт | guneshprint.uz; OSQ BOX WITH HANDLE |
| P5 | **Стикер круг 40–50 мм** | Заклейка, brand stamp | Прозрачный / белый | любая цифровая печать |
| P6 | **Кармашек для приборов** (опц.) | Зал / комбо | Крафт | OSQ POCKET |

### Не берём на старте

- Сложные custom-конструкции без пресс-формы (дорого).
- Окна с PET без нужды.
- Полноцветные «премиум-боксы» из AI-мудборда.
- Пенопласт / яркий глянец — бьёт по характеру «современный локальный».
