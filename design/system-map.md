# Карта системы: Brand Kit ≠ всё подряд

Коротко: **сначала ядро бренда, потом носители, потом Canva-шаблоны.**
Упаковка — не «отдельный мир» и не весь Brand Kit; это **приложение** ядра.

## Три слоя

```
┌─────────────────────────────────────────────┐
│  A. BRAND CORE (ядро)                       │
│  mark · wordmark · color · type · voice     │
│  → это и есть содержимое Canva Brand Kit      │
└──────────────────┬──────────────────────────┘
                   │ правила + файлы
┌──────────────────▼──────────────────────────┐
│  B. APPLICATIONS (носители)                 │
│  упаковка · стикеры · постеры · баннеры     │
│  меню · social posts · вывеска              │
│  → живут в Brand Book + Canva templates     │
└──────────────────┬──────────────────────────┘
                   │
┌──────────────────▼──────────────────────────┐
│  C. OPS / PRODUCTION                        │
│  поставщик бланков · тираж · КП · печать    │
│  → ops + finance; дизайн только stamp rules │
└─────────────────────────────────────────────┘
```

| Вопрос | Слой | Когда решаем |
| --- | --- | --- |
| Какая иконка? | A — core | **Сейчас** |
| Шрифт ChickenFit? | A — core | Сразу после mark |
| HEX цвета | A — core | Почти ок, lock после mark |
| Крафт vs белый бланк | B + C | Склонность: **крафт**; box vs wrap — **потом** |
| Печать лого на коробке | B | Только после A |
| Поставщик, цена, MOQ | C | После выбора конструкции |
| Canva Brand Kit | A → Canva | Когда A стабильно |
| Canva шаблоны постов | B → Canva | После A |

## Что такое Canva Brand Kit

Это **цифровая полка ядра A**:

- логотипы (mark, wordmark, lockup)
- цвета
- шрифты
- иногда brand photos / graphics

Это **не**:

- каталог упаковки OSQ
- прайс типографии
- весь брендбук целиком
- «решили коробку или wrap»

Упаковка в Canva появляется как **шаблон mockup / stamp placement** —
приложение B, после утверждённого mark.

## Что такое Brand Book (PDF)

Инструкция «как пользоваться ядром A на носителях B».  
Внутри есть *страницы* про упаковку, но решение «какой бланк купить» —
отдельный ops-выбор, не замена логотипа.

## Правило фокуса

Пока **A.mark** не выбран — не уходим в закупку упаковки и не строим
полноценный Brand Kit. Можно параллельно держать в голове «крафт», но
решение box/wrap — **следующий этап после mark**.
