# Политика безопасности

## Не хранить в репозитории

- API-ключи, токены, пароли, `.env`;
- платёжные данные и документы клиентов;
- персональные данные сотрудников и гостей;
- договоры с банковскими, паспортными и иными чувствительными реквизитами;
- production-дампы и приватные ссылки без контроля доступа.

## Работа AI-агентов

AI-агент не выполняет оплату, договор, платёж, force-push, удаление remote/ветки
или иное необратимое действие без явного подтверждения человека.
Обычный commit/push/PR в `chicken-fit-cafe` по задаче владельца допускается.
Для будущего QR-продукта обработка платежей и персональных данных требует
отдельного threat model и ADR.

## Сообщение об уязвимости

Репозиторий публичный: https://github.com/SharipovAkhror/chicken-fit-cafe  
Сообщайте уязвимости владельцу `@SharipovAkhror` приватно (не через публичный
issue с деталями эксплойта). Рекомендуется включить GitHub Private Vulnerability
Reporting в настройках репозитория.

## Реакция

1. Не распространять чувствительные данные дальше.
2. Зафиксировать минимально необходимый контекст без секрета.
3. Отозвать/ротировать скомпрометированный credential вне репозитория.
4. Создать приватный план исправления.
5. После устранения — ADR/postmortem без секретов.
