# Архив: экспорты Gemini

Статус: **неизменяемый архив**. Только для чтения.

## Что это

Исходные материалы, сгенерированные ранее в другой AI-системе (Gemini) на этапе
до создания этой операционной системы проекта. Сохранены дословно как
исторический контекст.

## Правила использования

1. **Файлы в этой папке нельзя редактировать.** Если нужна правка — создайте новый
   документ в рабочей области (`strategy/`, `brand/`, `design/`, `operations/`,
   `finance/`, `product/`) и сошлитесь на источник.
2. **Содержимое не является истиной.** Ни одно утверждение отсюда не считается
   подтверждённым фактом, пока оно не проведено через реестр
   [`knowledge/claims.yaml`](../../knowledge/claims.yaml) и не получило статус
   `confirmed`.
3. **Нейминг, логотип, цвета, шрифты, расчёты и цифры** из этих файлов —
   гипотезы, а не решения. Они переигрываются заново соответствующими ролями.
4. Каждый факт, извлечённый отсюда, должен ссылаться на конкретный файл и раздел
   в поле `source` реестра утверждений.
