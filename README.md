# Chicken Fit — касса

Касса кафе Chicken Fit (Самарканд): столы, заказы (порции, на вес, гарниры), оплата наличными / Click·Payme,
печать чеков 58/80 мм, экран кухни, смены с X/Z-отчётами, отчёты продаж, гостевое меню по QR.
Работает офлайн и синхронизируется через Supabase. Прод: https://chicken-fit-cafe.vercel.app

| Путь | Что |
|---|---|
| `/pos` | касса (вход по PIN) |
| `/kds` | экран кухни (PIN) |
| `/backup` | JSON-бэкап данных устройства без PIN |
| `/`, `/uz`, `/en` | гостевое меню |

Начать с [AGENTS.md](AGENTS.md): где что лежит, правила, ссылки на установку, миграции, релиз и runbook'и в [`docs/`](docs).
