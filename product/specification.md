# Спецификация QR-меню MVP

## Задача

Гость садится за стол, сканирует QR со стикера и видит меню заведения. Смотрит —
и всё. Заказать, добавить в корзину или оплатить внутри меню нельзя: заказ принимает
кассир, меню его не заменяет и не дублирует.

Архитектурное решение и его обоснование — [`ADR-004`](../decisions/ADR-004-qr-menu-mvp.md).

## User stories

| # | История | Критерий приёмки |
| :--- | :--- | :--- |
| U-1 | Как гость, я сканирую QR и сразу вижу меню | Страница открывается без промежуточных экранов и редиректов; контент читаем без JavaScript |
| U-2 | Как гость, я вижу фото, название, цену и состав позиции | Все четыре поля на карточке; фото отсутствует — плашка с логотипом, не пустое место |
| U-3 | Как гость, я быстро нахожу нужный раздел | Липкая полоса разделов, переход по якорю |
| U-4 | Как гость, я смотрю блюдо крупно | Тап по карточке открывает окно с большим фото и полным составом; закрывается по ×, Escape и тапу вне окна |
| U-5 | Как гость-иностранец, я читаю меню на своём языке | Переключатель RU / UZ / EN в шапке; непереведённая позиция показывает русский текст |
| U-6 | Как владелец, я добавляю и убираю позиции сам | Правка `content/menu.json` на github.com; обновление на сайте за 40–60 секунд |
| U-7 | Как владелец, я помечаю закончившееся блюдо | `"available": false` → карточка серая, бейдж «Нет в наличии», позиция остаётся видимой |
| U-8 | Как владелец, я не боюсь сломать меню опечаткой | Ошибка в JSON роняет сборку; гости продолжают видеть предыдущую версию |

## Функциональные границы

**Входит:** просмотр меню, разделы, карточка блюда, три языка, стоп-лист, редактирование
через JSON.

**Не входит:** заказ, корзина, оплата, бронирование, отзывы, авторизация, личный кабинет,
доставка, программа лояльности, поиск.

## Данные

Единственный источник — [`content/menu.json`](../content/menu.json), схема полей —
[`content/menu.schema.json`](../content/menu.schema.json), инструкция для владельца —
[`content/README.md`](../content/README.md).

- Персональные данные гостя **не собираются**: форм и полей ввода на страницах нет.
- Цены — целое число в сумах, хранятся открыто в публичном репозитории.
- Владелец данных — владелец проекта. Срок хранения — бессрочно, история в git.

## Состояния и отказы

| Ситуация | Поведение |
| :--- | :--- |
| Нет фото у позиции | Плашка с логотипом бренда |
| Нет перевода `uz` / `en` | Показывается русский текст |
| Пустой раздел | Раздел не выводится на страницу |
| Битый `menu.json` | Сборка падает, на сайте остаётся прошлая рабочая версия |
| Позиция кончилась | Серая карточка с бейджем «Нет в наличии» |
| Медленный мобильный интернет | HTML статический; фото ленивые, кроме первого экрана |
| JavaScript не выполнился | Карточки, цены и состав всё равно видны — не работает только увеличение фото |

## Accessibility

- Единственная интерактивная зона карточки — кнопка, доступная с клавиатуры.
- Окно блюда: `role="dialog"`, `aria-modal`, фокус переходит на «Закрыть», Escape закрывает,
  скролл фона заблокирован.
- Язык страницы объявлен на `<main lang>`; переключатель помечен `aria-current`.
- Цвета — токены бренда из `design/tokens.css`; тёмная схема принудительно отключена,
  чтобы меню не уезжало в серый на телефонах с ночным режимом.

## Производительность

- Все страницы статические, отдаются с CDN.
- Первые четыре фото грузятся сразу, остальные лениво.
- Лимит веса фото — 300 КБ, зафиксирован в [`public/menu/README.md`](../public/menu/README.md).

```bash
npm run build
```
