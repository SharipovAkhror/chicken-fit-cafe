# Спецификация оборудования кассовой зоны

## Цель

Определить минимальный и надёжный набор оборудования кассовой зоны кафе, его параметры и критерии выбора поставщиков.

## Область

Оборудование, непосредственно включённое в процесс расчёта и приёма платежей:
- **POS-терминал** (касса на планшете/ноутбуке)
- **Чековый принтер** (печать квитанций)
- **Денежный ящик** (хранение наличного)
- **Сканер** (штрихкоды; опционально)

Не входят: весы, дисплеи, микрофоны, видеокамеры, роутеры.

## 1. Чековый принтер 80mm

### Критерии

| Параметр | Требование | Обоснование |
|---|---|---|
| **Ширина печати** | 80 mm | Стандарт для кафе; 58 mm — только для мобильных |
| **Питание** | 24 В ± 10% | Стабильность, отсутствие скачков при пиках тока |
| **Интерфейсы** | USB + **LAN** (обязательно) | LAN для сетевого доступа, USB для отката на местный хост; BT не брать |
| **Автообрез** | Да, не менее 1 млн резов | Без ножа — рвёшь чек рукой, это недопустимо в кафе |
| **Печать** | ≥ 200 mm/s | Очередь не должна ждать |
| **Разрешение** | ≥ 203 DPI | Читаемость QR, текста, логотипа |
| **Ящик** | RJ11/RJ12 (порт денежного ящика) | Открывается по импульсу от принтера |
| **ESC/POS** | Да, стандартная команда set | Единый код печати на все принтеры и платформы |
| **Гарантия** | ≥ 12 месяцев с местным сервисом | Быстрая замена, запчасти в городе |

### Рекомендуемые модели (Ташкент, август 2026)

#### Бюджет: Xprinter XP-Q80A LAN

| | |
|---|---|
| **Цена** | ~650–750 тыс. сум (~$55–63) |
| **Тип** | Термопринтер, 80 mm, автообрез |
| **Интерфейсы** | USB + **LAN**, разъём денежного ящика |
| **Скорость** | 300 mm/s |
| **DPI** | 203 DPI |
| **Питание** | 24 В, 2.0 A |
| **Поставщики** | REGOS Software, Rofeev, RSG, MyLabel, Prom.uz |
| **Плюсы** | Низкая цена, LAN готов, быстрая отгрузка (1–2 дня) |
| **Минусы** | Гарантия зависит от продавца; найти сервис в регионах сложнее |

**Как заказать:**  
"Xprinter XP-Q80A именно в версии с LAN (не WiFi и не Bluetooth). 80 mm, автообрез, порт денежного ящика RJ11. Проверю RJ45 (разъём Ethernet) на задней панели при получении."

#### Средний класс: MERTECH Q80 Ethernet

| | |
|---|---|
| **Цена** | ~1.66 млн сум (~$140) |
| **Тип** | Термопринтер, 80 mm, автообрез |
| **Интерфейсы** | USB + **Ethernet** + RS232 |
| **Скорость** | ~200 mm/s |
| **DPI** | 203 DPI |
| **Питание** | 24 В |
| **Поставщик** | MERTECH (официальный в Ташкенте) |
| **Плюсы** | Гарантия 12 месяцев, сервис в Ташкенте, доставка по городу |
| **Минусы** | Втрое дороже; железо идентично Xprinter |

**Когда выбирать:**  
Если простой критичен, брать один MERTECH + один Xprinter на кухню. MERTECH — как основной с гарантией.

### Чек-лист приёмки

- [ ] На задней панели есть разъём **RJ45** (Ethernet), не только RJ11
- [ ] Блок питания маркирован **24 V** (не 9V, не 12V)
- [ ] Нож режет — сделать тестовую печать в магазине
- [ ] Все разъёмы туго, без люфтов
- [ ] Гарантийный талон подписан и дата указана

### Ввод в эксплуатацию

1. Установить **статический IP** через сервисное меню (кнопку PRINT, тест-кнопку или утилиту). На DHCP принтер после перезагрузки роутера меняет адрес → печать отваливается.
2. Записать IP, подсеть, шлюз в операционный лист.
3. Проверить доступ с кассы: `ping <IP принтера>`.

## 2. Денежный ящик

### Критерии

| Параметр | Требование |
|---|---|
| **Размер** | 330×350×100 mm или меньше (в нишу под кассу) |
| **Запирание** | Цилиндрический замок, ключ дублировать |
| **Срабатывание** | На импульс от принтера (принтер тянет провод за разъём RJ11/RJ12) |
| **Ячейки** | ≥ 4 отделения (купюры + монеты, разделение) |

### Поставка

Идёт в комплекте с принтером или заказывается отдельно на том же поставщике.

## 3. POS-терминал (касса)

### Требования к устройству

| Параметр | Требование |
|---|---|
| **ОС** | iOS (iPad) или Android (планшет) |
| **Память** | ≥ 4 GB RAM, ≥ 64 GB хранилище |
| **Экран** | 7–10.5 дюймов, яркость ≥ 350 cd/m² (читаемо при свете) |
| **Питание** | USB-C PD или Lightning, батарея 10+ часов |
| **Сетевой** | Wi-Fi 6 (802.11ax) или LTE (опционально) |
| **Приложение** | Самописная касса (см. [`product/printing-integration.md`](../product/printing-integration.md)) или лицензионное ПО |

### Рекомендуемые устройства

- **iPad 10th (2024)**, Wi-Fi + Cellular — стандарт для кафе в регионе
- **Xiaomi Pad 6 Pro** — бюджет для Android
- Любой MacBook / ноутбук (для фронт-офиса или кухни)

## 4. Сканер штрихкодов (опционально)

На старте не критичен — вводить позицию можно вручную.

Если вводится: USB-сканер (проводной) или Bluetooth (беспроводной). Рекомендация: проводной для стабильности.

## Процесс закупки

### Шаг 1: Выбор модели

Если бюджет ≤ 750 тыс.: **Xprinter XP-Q80A LAN**.  
Если есть 1.6–1.8 млн и критична гарантия: **MERTECH Q80**.  
Если неясно: позвонить в REGOS или Mertech, спросить, что есть в наличии и цена.

### Шаг 2: Звонок поставщику

```
— Добрый день. Нужен чековый принтер 80 mm.
— Какую модель ищете?
— Xprinter XP-Q80A именно с LAN, а не WiFi.
— У вас есть? Сколько? Когда доставка?
— Какой курс? Какие способы оплаты?
— Гарантия и сервис?
```

### Шаг 3: Доставка и приёмка

- Проверить по чек-листу выше.
- Установить статический IP.
- Протестировать печать.
- Подписать акт приёмки-передачи.

## Метрики контроля

| Метрика | Целевое значение |
|---|---|
| Время печати одного чека | ≤ 5 сек |
| Время от открытия ящика до закрытия | ≤ 3 сек |
| Uptime принтера (месячно) | ≥ 99.5% |
| Замена печатающей головки | ≥ 2 млн чеков (~3 года при 2000 чеков/день) |
