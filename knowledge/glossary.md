# Глоссарий

| Термин | Определение |
| :--- | :--- |
| Артефакт | Версионируемый результат работы в репозитории: документ, схема, код или запись решения |
| Утверждение (`claim`) | Проверяемая формулировка, которая может быть истинной или ложной |
| Факт | Утверждение со статусом `confirmed`, источником и зафиксированной проверкой |
| Гипотеза | Предположение для проверки; не используется как утверждённый вход |
| ADR | Architecture/Decision Record — запись значимого решения и его последствий |
| Handoff | Формальная передача результата между ролями с критериями готовности |
| Source of Truth | Единственный авторитетный файл для конкретного типа данных |
| Project owner | Человек, принимающий критичные решения и разрешающий эскалации |
| Cross-review | Проверка результата другой ролью, затрагиваемой решением |
| KDS | Kitchen Display System; термин не означает, что система уже утверждена |
