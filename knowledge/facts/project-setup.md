# Подтверждённые настройки проекта

На текущем этапе подтверждены организационные решения:

1. Основной язык документов — русский; технические термины допустимы на английском.
2. Рабочий интерфейс ОС v1 — файлы и GitHub-процесс.
3. Ядро v1 состоит из шести AI-ролей:
   - системный архитектор;
   - бренд-стратег;
   - визуальный дизайнер;
   - операционный менеджер;
   - финансовый аналитик;
   - продуктовый разработчик.
4. Материалы Gemini не наследуются как решения; допускается перенос только
   проверенных утверждений через `knowledge/claims.yaml`.
5. Удалённый репозиторий: `https://github.com/SharipovAkhror/chicken-fit-cafe`
   (ADR-003). Локальная папка клона: `chicken-fit-cafe`.
6. Agent harness: канон в `AGENTS.md`, vendor-стабы, `STATUS.md`, CI-валидатор.

Бизнес-модель, конкретное помещение, меню, экономика и цифровой продукт в
деталях пока не полностью подтверждены (см. claims со статусом needs-verification).
