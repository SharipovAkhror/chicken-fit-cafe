# Фото блюд

Сюда кладём картинки для QR-меню. Путь в [`content/menu.json`](../../content/menu.json)
пишется от корня сайта: файл `public/menu/samsa-burger-classic.webp` → `"image": "/menu/samsa-burger-classic.webp"`.

## Требования

| | |
|---|---|
| Формат | `.webp`, запасной вариант — `.jpg` |
| Размер | 1200 × 900 px (пропорция 4:3) |
| Вес | **до 300 КБ.** Это главное: гость открывает меню с телефона в кафе |
| Имя файла | как `id` блюда: `samsa-burger-classic.webp` |
| Кадр | блюдо по центру, обрезка по 4:3 не должна резать важное |

Тяжёлые фото — единственный способ сделать это меню медленным. Двенадцать картинок
по 3 МБ превратятся в 36 МБ на мобильном интернете. Сжимай перед загрузкой
(любой конвертер в webp с качеством 80 даёт нужный вес).

## Пока фото нет

Оставляй `"image": ""`. Гость увидит плашку с логотипом — это лучше, чем битая картинка
или чужой стоковый снимок.

Правила съёмки и стиль кадра — в [`design/prompts/food-photography-bible.md`](../../design/prompts/food-photography-bible.md).
