# Карта проекта

## Северная звезда текущего этапа

Сделать работу над запуском кафе проверяемой: любой участник должен понимать,
что является фактом, какое решение принято, кто отвечает за следующий шаг и где
лежит актуальный результат.

## Потоки работы

| Поток | Source of Truth | Владелец | Текущий шлюз |
| :--- | :--- | :--- | :--- |
| Стратегия | `strategy/` | Бренд-стратег + владелец | Верификация бизнес-брифа |
| Бренд | `brand/` | Бренд-стратег | Стратегический бриф approved |
| Визуальная система | `design/` | Визуальный дизайнер | Бренд-платформа approved |
| Операции | `operations/` | Операционный менеджер | Подтверждённая модель сервиса |
| Финансы | `finance/` | Финансовый аналитик | Проверенные цены и допущения |
| QR-продукт | `product/` | Продуктовый разработчик | Service blueprint + требования approved |
| Знания | `knowledge/` | Системный архитектор | Непрерывная проверка claims |
| Решения | `decisions/` | Системный архитектор | ADR для каждого критичного решения |

## Критические зависимости

```
Проверенные факты
  ├─→ Бизнес-стратегия ─→ Бренд-стратегия ─→ Визуальная система
  ├─→ Операционная модель ────────────────┐
  └─→ Финансовые допущения ──────────────┼─→ QR-продукт
                                        └─→ План запуска
```

Ни дизайн, ни разработка не должны обходить входные шлюзы. Если вход не
`approved`, работа допускается только как явно помеченный `draft`/прототип.
