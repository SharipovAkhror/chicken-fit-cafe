# Как менять меню

Всё меню — один файл [`menu.json`](menu.json). Больше ничего трогать не нужно:
ни код, ни дизайн, ни Vercel. Изменил файл → через минуту новое меню у всех гостей.

## С телефона, за минуту

1. Открой [`content/menu.json` на GitHub](https://github.com/SharipovAkhror/chicken-fit-cafe/blob/main/content/menu.json).
2. Нажми карандаш (**Edit**).
3. Поправь текст.
4. Внизу — **Commit changes**, короткое описание, зелёная кнопка.
5. Vercel сам пересоберёт сайт. Через 40–60 секунд обнови страницу меню.

QR-код при этом **никогда не меняется** — он ведёт на адрес сайта, а не на конкретное меню.

## Добавить блюдо

Скопируй этот кусок внутрь нужного раздела, в список `"items"`, и не забудь запятую
между позициями:

```json
        {
          "id": "novoe-blyudo",
          "name": {
            "ru": "Новое блюдо",
            "uz": "Yangi taom",
            "en": "New Dish"
          },
          "description": {
            "ru": "Из чего оно",
            "uz": "Nimadan tayyorlangan",
            "en": "What is inside"
          },
          "price": 35000,
          "image": "",
          "available": true
        }
```

## Убрать блюдо

Два способа, оба нормальные:

- **Кончилось на сегодня** → поменяй `"available": true` на `"available": false`.
  Позиция останется в меню с пометкой «Нет в наличии», серая и неактивная.
- **Убрали навсегда** → удали весь блок от `{` до `}` вместе с запятой перед ним.

## Поменять цену

Найди `"price"` и напиши новое число **без пробелов и без слова «сум»**:
`45000`, а не `45 000 сум`. Пробелы и валюту сайт расставит сам.

## Добавить фото

1. Залей файл в папку [`public/menu/`](../public/menu) (кнопка **Add file → Upload files** на GitHub).
2. В блоке блюда пропиши путь: `"image": "/menu/имя-файла.webp"`.

Требования к фото — в [`public/menu/README.md`](../public/menu/README.md).
Пока фото нет, оставь `"image": ""` — гость увидит аккуратную плашку с логотипом,
а не битую картинку.

## Поля позиции

| Поле | Обязательно | Что писать |
|---|---|---|
| `id` | да | Латиница в нижнем регистре и дефисы: `samsa-burger-classic`. Не повторяется. |
| `name` | да | Название. `ru` обязателен, `uz` и `en` — по желанию. |
| `description` | нет | Состав, 1–2 строки. |
| `price` | да | Целое число в сумах: `45000`. |
| `image` | нет | `/menu/файл.webp` или пустая строка. |
| `available` | нет | `false` — «нет в наличии». Если не писать, считается `true`. |
| `kcal` | нет | Калории. Показываем, только если указано. |
| `weight` | нет | Вес порции в граммах. Показываем, только если указано. |

Вместо трёх языков можно написать одну строку — она покажется всем:
`"name": "Coca-Cola 0,5"`. Так удобно для брендов и напитков.

Если `uz` или `en` не заполнены, гость увидит русский текст. Меню не сломается,
просто перевода не будет.

## Если ошибся

Ничего страшного не случится. Перед каждым деплоем запускается
[`tools/validate-menu.mjs`](../tools/validate-menu.mjs): он проверяет запятые, кавычки,
цены, повторяющиеся `id` и наличие файлов фото.

- Ошибка → **сборка падает, на сайте остаётся прежнее рабочее меню**. В Vercel будет
  видно, в какой строке проблема. Исправил, закоммитил ещё раз — поехало дальше.
- Гости в этот момент ничего не замечают.

Проверить меню у себя до коммита:

```bash
npm run validate:menu
```

## Чего здесь нет

Заказа, корзины, оплаты и брони. Меню — только чтобы посмотреть. Это осознанное решение,
зафиксировано в [`ADR-004`](../decisions/ADR-004-qr-menu-mvp.md).
