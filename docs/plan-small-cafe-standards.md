# План: стандарты малого кафе (1 точка, 1 Windows-касса, сменные телефоны)
Статус: план, ничего не задеплоено. Ветка plan/small-cafe-standards (от feat/pins-devices, не смержено в main).

## Факты из кода (проверено)
- Вход по PIN (bcrypt), PIN = идентификатор сотрудника; сессия 16 ч (pos_login), роли admin/cashier/kitchen, лимит 5 ошибок/5 мин на устройство + 30/5 мин глобально (0015).
- Смены: таблица shifts (initial_cash, counted_cash, z_snapshot), X/Z-отчёт печатаются из ShiftView, повтор печати последнего Z. Открытие/закрытие — вручную.
- order_events пишет created/updated со staff_id (статус+сумма) — журнал есть, но без диффа позиций, скидок, отмен.
- pos_admin_set_pin (0015, ветка feat/pins-devices): валидация, запрет слабых/повторяющихся PIN. НЕ отзывает старые сессии сотрудника.
- device_id/label — только атрибуция, подделываемо. Манифест: orientation any, standalone.
- Сид-PIN из 0007/0008 в проде не менялись (pin_changed_at null) — критично.

## P0 безопасность (после закрытия, риск для смены: нулевой при выкате после Z)
1. Новые PIN 6 цифр для каждого (владелец даёт через секретное поле, не в чате). Ставит агент через pos_admin_set_pin.
2. Миграция: при смене PIN — delete staff_sessions этого сотрудника; RPC «выйти везде» для admin.
3. Деактивировать тестовых/сид-сотрудников, которых нет в реальности.
4. Сессии телефонов короче (напр. 12 ч), касса — до конца смены.

## P0/P1 операции
- Смена: при первом входе кассира, если смены нет — экран «Открыть смену» (только сумма в кассе). Закрытие — мастер: пересчёт наличных → расхождение → Z → печать → выход.
- Авто-напоминание: если смена открыта позже N часа после времени закрытия — баннер админу; Z-итог директору (email/Telegram — по выбору владельца).
- Модель доступа: касса = доверенный профиль (метка устройства «Касса»); телефоны = личный PIN + роль, без одобрения устройств. Директор (admin) — отчёты/меню/PIN с телефона.
- Полный журнал: order_events пишет отмены, скидки, изменения позиций, переоткрытие оплаченных.

## P1 UX
- Касса landscape 16:9 touch: крупные цели ≥48px, меню слева/чек справа, без hover.
- Телефон: одна колонка, нижняя навигация, кассир — быстрый заказ; директор — сводка дня.
- После входа: 3-шаговая подсказка по роли (однократно, кнопка «?» всегда), понятные пустые состояния.

## НЕ строим
- Одобрение устройств/MDM для телефонов кассиров, мульти-филиал, биометрия, складской учёт, сложные права сверх 3 ролей.
