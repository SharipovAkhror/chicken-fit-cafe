# ADR-002: концепция до названия

## Контекст

Пилот 001 изначально предполагал выбор направления нейминга до визуального
дизайна. При выборе названия из абстрактных списков владелец проекта отклонил
подход: имя без визуального и смыслового мира получалось формальным и слабо
связанным с продуктом.

## Решение

Меняем порядок для этого бренда:

1. Позиционирование утверждено (C-019).
2. Визуальный дизайнер создаёт минимум три целостные визуальные концепции
   **без финального названия** (используются рабочие кодовые метки).
3. Владелец выбирает одну концепцию.
4. Бренд-стратег разрабатывает нейминг **внутри выбранного мира**.
5. Проводится проверка названия, затем финальный логотип и брендбук.

Черновики нейминга (`brand/naming-shortlist.md`, `brand/naming-round-2.md`)
понижены до архивных материалов и не являются решением.

## Последствия

- Контракт визуального дизайнера допускает старт без `approved` нейминга при
  утверждённом позиционировании; это отклонение действует в рамках данного бренда.
- Название обязано опираться на выбранный визуальный мир, а не наоборот.
- Требуется отдельный шаг проверки названия перед финальным логотипом.

## Статус claim

C-019 (позиционирование) — `confirmed`; служит основанием для концепций.
