# ADR-001: Репозиторий как источник истины

## Контекст

Проекту нужна воспроизводимая совместная работа владельца и AI-ролей. Исходные материалы содержат смесь фактов, предположений и ранее сгенерированных решений.

## Решение

Использовать Git-репозиторий как единственный рабочий источник истины. Факты проходят через `knowledge/claims.yaml`; значимые решения — через ADR; работа — через issue, ветку и pull request.

## Последствия

- Изменения получают историю и ответственного.
- Непроверенные данные нельзя незаметно превратить в основу решения.
- Работа требует дисциплины метаданных и ревью.
- Архив сохраняется, но не получает нормативного статуса.

## Проверка

CI проверяет структуру, ссылки, метаданные и согласованность approved claims.
