# Как начать и закончить день (для кассира)

**Утро**
1. Включите кассу, введите свой PIN.
2. Откроется экран «Начало дня». Проверьте размен в ящике.
3. Сумма совпадает — нажмите большую кнопку «Открыть смену». Не совпадает — «Изменить сумму», введите, затем «Открыть смену».
4. Работайте: «Столы» → стол → блюда → «Оплата».

**Вечер** (после 22:00 появится напоминание «Пора закрыть смену»)
5. «Смена» → «Закрыть смену (Z)». Пересчитайте наличные.
6. Совпало с «Ожидается» — сразу «Закрыть смену и напечатать Z». Не совпало — «В кассе другая сумма», введите и напишите причину.
7. Заберите Z-отчёт и нажмите «Выйти из кассы».
